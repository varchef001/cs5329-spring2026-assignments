# Advanced Course Planner Datasets

Schema:
```json
{
  "course_id": "CS301",
  "course_name": "Machine Learning",
  "program": "Computer Science",
  "concentration": "AI & ML",
  "category": "Required",
  "prerequisites": ["AI301", "DS301"]
}
```

Use `course_id` for algorithm logic.
Use `course_name`, `program`, `concentration`, and `category` for filtering and display.
