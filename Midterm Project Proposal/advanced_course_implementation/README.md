
# Advanced Course Planner Implementation

This implementation supports:
- prerequisite-based scheduling
- baseline and optimized algorithms
- multi-program course catalogs
- concentration-aware planning
- elective selection
- automatic prerequisite inclusion
- runtime and memory benchmarking

## Structure

course_planner_advanced_implementation/
├── src/
│   ├── baseline.py
│   ├── optimized.py
│   ├── validator.py
│   └── catalog_utils.py
├── main.py
├── benchmark.py
└── README.md

## Run

```bash
python3 main.py
```

Use the advanced catalog dataset when prompted, for example:
`../datasets/courses_advanced_catalog.json`
